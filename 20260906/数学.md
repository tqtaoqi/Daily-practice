# 七年级数学竞赛题精选

## 题目：

【背景】
同一组数用不同的形式表示时，数的对应关系可能会"打乱顺序"，但这组数中谁都不会多、谁也不会少。因此两种形式中的特殊数（如 $0$ 和 $1$）一定能够对应起来，由此可以锁定字母之间的关系。

例如：若三个数 $2$、$x$、$y$ 与 $x$、$3$、$y+1$ 是同一组数，则可由"出现 $3$ 而另一组没有"判断 $3$ 必为 $2$、$x$、$y$ 中的某一个，逐步推出各字母的值。

【问题】
三个互不相等的有理数，既可以表示为 $1$、$a+b$、$a$ 这三个数的形式，又可以表示为 $0$、$\dfrac{b}{a}$、$b$ 这三个数的形式。

求 $a^{2026}+b^{2027}$ 的值。
